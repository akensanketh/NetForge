Standard V2Ray-Compatible Client Documentation

Connection Guides.
Connect Any Device in 60 Seconds.

NETFORGE natively supports standard, open-source V2Ray clients. No bloatware or background monitoring services. Choose your operating system below for detailed step-by-step instructions on importing your V2Ray (VMess/VLESS) configuration.

🚧 Client Under Development: The dedicated NETFORGE Windows client is currently under active development. Downloads and direct connections are temporarily locked.

Connecting on Windows 10 & 11

The open-source v2rayN client for Windows provides stealth proxying, traffic obfuscation, and system-wide routing via WebSocket + TLS.

1

Download Official v2rayN for Windows

Download the latest release of v2rayN-With-Core.zip from GitHub. Extract the archive and launch v2rayN.exe.

2

Download Your Configuration File

Log in to your NETFORGE Customer Portal, select your desired server location (e.g. Zurich, New York, or Tokyo), and click Copy vmess:// Link (or download config.json).

3

Import & Activate Tunnel

In v2rayN, click Servers → Import bulk URL from clipboard (or press Ctrl+V), then enable Set System Proxy.

💡 Pro-Tip (Kill Switch): Choose "PAC" mode if you only want blocked sites to route through V2Ray, or "Global" mode for 100% traffic encryption across all applications.

Connecting on macOS (Apple Silicon & Intel)

Supports native Network Extension APIs with menu-bar quick toggle.

1

Install Official App from Mac App Store

Install V2RayX, Clash Verge, or FoXray from GitHub or the Mac App Store.

2

Copy NETFORGE V2Ray Link or Config

Navigate to your Customer Portal and click Copy vmess:// Link (or download config.json).

3

Import Tunnel & Allow System Permission

In your V2Ray client, select Import from clipboard. Set routing mode to Global or Rule to activate anti-censorship browsing.

Connecting on Linux (Ubuntu / Debian / Arch / Fedora)

Runs via standard kernel module using wg-quick or NetworkManager.

1

Install V2Ray Core

Install the official V2Ray package using your distro's standard package manager:

# Ubuntu / Debian
sudo apt update && sudo apt install v2ray -y

# Fedora
sudo dnf install v2ray -y

# Arch Linux
sudo pacman -S v2ray
2

Place Configuration in /etc/v2ray/

Save your configuration file from the Customer Portal to /etc/v2ray/config.json:

sudo cp ~/Downloads/netforge-v2ray-*.json /etc/v2ray/config.json
sudo chmod 644 /etc/v2ray/config.json
3

Bring Up Tunnel & Verify Handshake

sudo systemctl restart v2ray
sudo systemctl status v2ray

To stop the proxy service when finished: sudo systemctl stop v2ray

Connecting on iPhone & iPad (iOS)

Seamless on-demand connection with zero background battery strain.

1

Install Official App

Download Shadowrocket, Streisand, FoXray, or Sing-box from the Apple App Store.

2

Scan QR Code from Customer Portal

In your computer's browser, open your Customer Portal, click View QR Code for your device profile.

3

Scan with Mobile Camera

In your iOS app, tap + → Scan QR code (or import from clipboard). Tap the imported node and toggle the main connection switch to ON.

🚧 Client Under Development: The dedicated NETFORGE Android client is currently under active development. Downloads and direct connections are temporarily locked.

Connecting on Android

Works with Android 8+ on phones, tablets, and Android TV.

1

Install v2rayNG

Install the open-source v2rayNG app from Google Play Store or GitHub releases.

2

Import via QR Code or Clipboard

Tap the blue + button at bottom right → choose Scan from QR code (scanned from your portal) or Import from file or archive.

3

Enable Always-On VPN

In Android Settings → Network & internet → VPN → tap the gear icon next to NETFORGE → toggle Always-on VPN and Block connections without VPN for permanent hardware kill switch.

Connecting on OpenWrt / pfSense / GL.iNet Routers

Protect every Smart TV, IoT device, gaming console, and phone connected to your home Wi-Fi automatically.

1

Generate Router Profile in Portal

In the Customer Portal, create a device named "Home-Router" to allocate a dedicated IP subnet (e.g. 10.10.2.2/32).

2

Sample OpenWrt V2Ray Configuration Structure

[Interface]
PrivateKey = MKEY...YOUR_ROUTER_PRIVATE_KEY...KEY=
Address = 10.10.2.2/32
DNS = 10.10.0.1

[Peer]
PublicKey = NETF...SERVER_PUBLIC_KEY...ORGES=
Endpoint = ch-zrh-04.netforge.internal:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
3

Firewall Zone Assignment

Configure the V2Ray inbound port or TPROXY transparent redirect to the WAN firewall zone with masquerade enabled so all LAN clients share the proxy.
