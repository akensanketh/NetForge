Standard V2Ray Client Connection Instructions

Quick reference guides to connect using standard open-source V2Ray clients (v2rayN, v2rayNG, Shadowrocket).

🪟 Windows & 🍎 macOS (Desktop)

  1. Install v2rayN (Windows) or V2RayX / Clash Verge (macOS).
  2. Go to the V2Ray Configs tab and click Download V2Ray Config (.json).
  3. In your V2Ray client, select Import from clipboard (vmess://) or load config.json.
  4. Click Activate to establish your encrypted tunnel.

📱 iPhone, iPad & Android (Mobile)

  1. Install v2rayNG (Android) or Shadowrocket / Streisand / FoXray (iOS).
  2. In this dashboard, go to the V2Ray Configs tab and click View Mobile QR Code.
  3. In your mobile V2Ray app, tap + → Scan QR Code (or import from clipboard).
  4. Scan the QR on your screen, name the tunnel NETFORGE, and tap connect!

🐧 Linux CLI (Ubuntu, Debian, Arch, Fedora)

# Place your downloaded config into /etc/v2ray/
sudo cp ~/Downloads/netforge-v2ray-*.json /etc/v2ray/config.json
sudo chmod 644 /etc/v2ray/config.json

# Bring the interface up
sudo systemctl restart v2ray

# Verify active cryptographic handshake
sudo systemctl status v2ray
